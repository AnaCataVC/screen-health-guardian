# Release v1.0.0

Welcome to the first official release of **Work Health Timer**! 🎉 

A lightweight Windows desktop application designed to send periodic health alerts while you work, helping you maintain good habits without unnecessary interruptions.

## ✨ Features
* **Smart Activity Detection:** Uses Windows native APIs to only count active time (keyboard/mouse). Timers pause automatically if you are idle for 2+ minutes.
* **Health Intervals:** Includes customizable reminders for Eye Rest (20-20-20 rule) and Posture checks.
* **System Tray Integration:** Runs quietly in the background with a heart icon in the notification area for quick access to pause, settings, or quit.
* **Fully Configurable:** Adjust all intervals, idle thresholds, sounds, and auto-start behaviors via the built-in Settings window.
* **Bilingual Support:** Interface available in both English and Spanish.
* **Standalone Executable:** No Python installation required to run.

# Lanzamiento v1.0.0

¡Bienvenidos al primer lanzamiento oficial de **Work Health Timer**! 🎉 

Una aplicación de escritorio ligera para Windows diseñada para enviar alertas periódicas de salud mientras trabajas, ayudándote a mantener buenos hábitos sin interrupciones innecesarias.

## ✨ Características Principales
* **Detección Inteligente de Actividad:** Usa la API nativa de Windows para contar solo el tiempo activo (teclado/ratón). Los temporizadores se pausan automáticamente si estás inactivo por más de 2 minutos.
* **Intervalos de Salud:** Incluye recordatorios personalizables para Descanso Visual (regla 20-20-20) y controles de Postura.
* **Integración en la Bandeja del Sistema:** Se ejecuta silenciosamente en segundo plano con un icono de corazón en el área de notificaciones para acceso rápido (pausar, ajustes o salir).
* **Totalmente Configurable:** Ajusta todos los intervalos, umbrales de inactividad, sonidos y el inicio automático desde la ventana de Ajustes integrada.
* **Soporte Bilingüe:** Interfaz disponible tanto en Inglés como en Español.
* **Ejecutable Independiente:** No requiere instalación de Python para funcionar.
